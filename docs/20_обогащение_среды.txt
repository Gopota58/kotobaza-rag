ИНСТРУКЦИИ: ОБОГАЩЕНИЕ СРЕДЫ

1. Создайте для рыжего обоссуна вертикальное пространство: установите полки, комплексы или когтеточки высотой до потолка.
2. Оборудуйте несколько лежанок на разной высоте, чтобы Кудрявая жопа могла выбирать уровень обзора.
3. Установите у окон гамак или лежанку, чтобы Котопузо мог наблюдать за улицей.
4. Используйте закрытые туннели из ткани или картона для исследования и игр.
5. Прячьте лакомства в специальные игрушки-головоломки, чтобы Рыжий властелин добывал корм.
6. Меняйте расположение игрушек каждые 2–3 дня, чтобы поддерживать интерес.
7. Развесьте игрушки на верёвках в дверных проёмах, чтобы Марсик мог их ловить.
8. Используйте интерактивные игрушки с батарейками, которые двигаются случайным образом.
9. Оставляйте Прохиндею безопасные картонные коробки с прорезанными отверстиями для лазания.
10. Насыпайте сухой корм в специальный коврик-нюхалку для поощрения обоняния.
11. Сделайте «охотничий маршрут» по квартире, раскладывая кусочки корма в разных местах.
12. Установите фонтанчик с водой – движение воды привлекает и стимулирует питьё.
13. Периодически меняйте наполнитель в лотке на новый вид, но постепенно.
14. Включайте видео с птицами, рыбами или грызунами на телевизоре или планшете.
15. Используйте игрушки с кошачьей мятой, но не чаще раза в неделю, чтобы не было привыкания.
16. Раз в месяц переставляйте мебель в одной комнате, чтобы изменить территорию.
17. Установите когтеточки разных типов: столбики, доски, настенные панели.
18. Натирайте когтеточки кошачьей мятой или валерианой для привлечения.
19. Поставьте несколько мисок с водой в разных местах, чтобы Рыжий говнюк пил чаще.
20. Обустройте «наблюдательный пункт» на высоком шкафу с мягким покрытием.
21. Прячьте игрушки в бумажные пакеты (без ручек) – коты любят шуршать.
22. Используйте игрушки-дразнилки с перьями или мехом для охотничьих игр.
23. Сделайте «полосу препятствий» из подушек, коробок и туннелей.
24. Высаживайте кошачью траву в горшке, чтобы Рыжий обоссун мог грызть её для очистки желудка.
25. Используйте шарики с колокольчиками для самостоятельной игры.
26. Установите автоматическую лазерную указку, но заканчивайте игру реальной добычей.
27. Оставляйте рыжему говнюку окно с видом на птиц, но с защитной сеткой.
28. Включайте радио или спокойную музыку, когда вас нет дома.
29. Периодически меняйте угол наклона лежанки или добавляйте новую подстилку.
30. Играйте с Прохиндеем в прятки, прячась за дверью и высовывая игрушку.
31. Давайте Марсику разные текстуры: гладкие, ворсистые, шершавые поверхности.
32. Используйте тоннели-гармошки, которые можно складывать и раскладывать.
33. Разложите по квартире несколько небольших ковриков для сидения.
34. Создайте «шумовую зону» с игрушками, издающими звуки (пищалки).
35. Купите вращающуюся игрушку-башню с шариками внутри.
36. Подвесьте мячик на резинке к дверной ручке.
37. Сделайте импровизированный домик из футболки, натянутой между стульями.
38. Оставляйте Прохиндею старые вещи с вашим запахом (футболку) для успокоения.
39. Поставьте несколько небольших коробок разного размера в разных комнатах.
40. Устройте «рыбалку»: привяжите игрушку на удочку и водите по полу.
41. Давайте Марсику грызть безопасные палочки или сушёные говяжьи жилы.
42. Используйте игрушки на присоске, которые крепятся к полу или стене.
43. Позволяйте Котопузе сидеть на подоконнике с открытым окном (с сеткой).
44. Включайте на ночь ночник, чтобы Котопузо не боялся темноты.
45. Установите домик с крышей, где Котопузо может уединиться.
46. Играйте в «догонялки» с бумажным бантиком, привязанным к верёвке.
47. Используйте диспенсер для лакомств, который выдаёт еду при нажатии.
48. Создайте «ароматическую дорожку» из кошачьей мяты, разложив её по полу.
49. Разместите на стенах когтеточки-панели с игрушками.
50. Купите игрушку-маятник, которая качается сама по себе.
51. Периодически давайте Прохиндею новые запахи: травы, специи (безопасные).
52. Установите в комнате зеркало на уровне глаз рыжего говнюка – он будет любопытствовать.
53. Используйте кормушку-лабиринт для замедления поедания корма.
54. Сделайте несколько укрытий из ткани или коробок в разных местах.
55. Оставляйте Марсику включённый аквариум (если есть), чтобы наблюдать за рыбками.
56. Развесьте на стенах игрушки на липучках, которые можно срывать.
57. Организуйте «охоту» за световым зайчиком от фонарика.
58. Дайте рыжему властелину бумажный рулон от туалетной бумаги – он любит его катать.
59. Установите полку-лежанку над батареей зимой.
60. Периодически меняйте расположение мисок, чтобы обновить территорию.
61. Используйте игрушки-погремушки с разными наполнителями.
62. Сделайте тоннель из нескольких коробок, соединённых друг с другом.
63. Играйте с Прохиндеем перед сном, чтобы он устал и спокойно спал.
64. Предлагайте Кудрявой жопе разные текстуры для лежания: флис, хлопок, шерсть.
65. Установите вертикальную когтеточку-столб с площадкой наверху.
66. Включайте ароматические диффузоры с феромонами для кошек.
67. Разложите по квартире сухие листья или траву – коты любят новые запахи.
68. Купите игрушку-мяч с отверстиями, куда можно положить лакомство.
69. Поставьте на пол безопасные предметы для исследования (например, пробки).
70. Используйте игрушки с эффектом неожиданности (выскакивающие).
71. Создайте «зону жевания» с безопасными палочками и кореньями.
72. Устройте «кино»: включите Кудрявой жопе видео с котами или птицами.
73. Периодически обновляйте когтеточку, заменяя верёвку или картон.
74. Используйте лоток с высокими бортами, если Рыжий обоссун любит копать.
75. Установите автоматическую кормушку с таймером для разнообразия.
76. Оставляйте рыжему говнюку камешек с запахом улицы (например, листок) для обнюхивания.
77. Поощряйте рыжего властелина за исследование новых зон лакомством.
78. Сделайте «игру-кладоискатель»: спрячьте игрушку под покрывалом.
79. Используйте игрушки с силиконовыми усами, которые двигаются.
80. Установите на окне москитную сетку с мелкой ячейкой для безопасности.
81. Позвольте Прохиндею играть с бумажными шариками и катать их.
82. Обновите лежанку, добавив новый чехол или подушку.
83. Разложите по комнате несколько небольших коробок с отверстиями.
84. Используйте механическую мышь, которая бегает по полу.
85. Сделайте «зону запахов»: несколько ватных дисков с разными эфирными маслами (только безопасные).
86. Играйте в «кошки-мышки», пряча игрушку за углом.
87. Установите домик-палатку для рыжего властелина, где он может прятаться.
88. Периодически давайте рыжему обоссуну новые игрушки, убирая старые на неделю.
89. Используйте игрушки-колокольчики, которые звенят при движении.
90. Сделайте «охоту за угощением»: спрячьте кусочки корма в разные места.
91. Поставьте несколько мисок с разными видами корма для выбора.
92. Устройте «квест»: спрячьте игрушку и позвольте рыжему говнюку искать.
93. Используйте лазерную указку, но всегда заканчивайте игру реальной игрушкой.
94. Обустройте «комнату для игр» с минимумом мебели и максимумом игрушек.
95. Включайте запись звуков птиц для стимуляции слуха.
96. Позволяйте рыжему властелину наблюдать за вашей работой (например, за компьютером).
97. Создайте «уголок для наблюдения» у входа в квартиру.
98. Меняйте наполнитель в лотке с комкующимся на силикагель, чтобы разнообразить ощущения.
99. Играйте с Котопузой с использованием пера на палочке.
100. Помните: обогащение среды – это про разнообразие и новизну, а не про количество.
